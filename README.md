# .github

opendata-kr 조직의 공개 프로필과 공통 커뮤니티 헬스 파일을 담는 리포지토리입니다.

이 리포의 파일은 조직의 다른 리포가 같은 종류의 파일을 갖지 않을 때 자동으로 상속됩니다. 상속 규칙은 [GitHub 문서](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file)를 참고하세요.

## 구성

| 파일 | 역할 |
|---|---|
| `profile/README.md` | 조직 공개 프로필 (Overview 탭에 표시) |
| `CONTRIBUTING.md` | 기여 가이드 |
| `CODE_OF_CONDUCT.md` | 행동 강령 |
| `SECURITY.md` | 보안 취약점 신고 절차 |
| `SUPPORT.md` | 도움받는 경로 |
| `GOVERNANCE.md` | 프로젝트 거버넌스 |
| `.github/ISSUE_TEMPLATE/`, `.github/PULL_REQUEST_TEMPLATE.md` | 이슈, PR 템플릿 |

`LICENSE` 는 상속되지 않으므로 각 서비스 리포에 개별로 둡니다.
